# Data provenance, units, endpoints and analysis rules

All three CSV files are the processed benchmark versions from DeepSurv (Katzman et al., 2018,
BMC Medical Research Methodology 18:24, doi:10.1186/s12874-018-0482-1). The originals are
HDF5 files in https://github.com/jaredleekatzman/DeepSurv/tree/master/experiments/data. PyCox
0.3.0 loads the same files and concatenates the `train` then `test` partitions
(`pycox/datasets/from_deepsurv.py`). The CSVs (regenerated by `download_data.py` into `data/`) are only read.

Evidence levels used below:
- **checked**: compared directly against the original DeepSurv HDF5 files (downloaded 2026-10-31;
  the same checksums were re-verified by `download_data.py` on 2026-11-13).
- **consistent**: numerically consistent with the cited primary source, but not re-checked against
  that source's text during this provenance review.
- The dataset descriptions in the DeepSurv article itself were not re-read during this review; the
  endpoint wording below follows the checked data and the cited primary studies.

## Units and endpoints

| dataset | time unit | endpoint used in this study | evidence |
|---|---|---|---|
| SUPPORT | **days** | death from any cause (overall survival) | checked: integer durations 3-2029 in CSV and HDF5. Consistent: the SUPPORT follow-up variable (days to death or last contact) has this range. |
| METABRIC | **months** | death (benchmark coding) | checked: durations 0.0-355.2 in CSV and HDF5. Consistent: 355.2 is the maximum overall-survival time in months of the METABRIC cohort. The processed data contain a death indicator without a verified cause-of-death label, so whether deaths from other causes are events follows the DeepSurv processing and cannot be confirmed from the data; the manuscript therefore reports this endpoint as "death (benchmark coding)", not as a verified overall-survival or disease-specific endpoint. |
| Rotterdam-GBSG | **months** | recurrence-free survival (recurrence or death) | checked: GBSG partition minimum 0.26283 and maximum 87.35934 equal 8 and 2659 days divided by 30.4375 (days per month); Rotterdam partition ends at exactly 84.0 months (7 years). ## Analysis-set rule (identical for all datasets)

Records with a duration <= 0, a missing duration, or an event code outside {0, 1} are excluded
from the analysis set. This affects exactly one record: METABRIC CSV row with duration 0.0 and
event 0 (in DeepSurv's own test partition). A record censored at time 0 is never observed at risk,
so excluding it leaves Kaplan-Meier estimates, IPCW weights and the Cox partial likelihood
unchanged. The rule is applied in `common.load_dataset`, logged, and recorded in
`outputs/frozen_design.json` and each split file. The CSV is not modified.

## GBSG cohort membership

The CSV has no cohort column (Stage 0). `recover_gbsg_cohort.py` matches every CSV record by
value (7 covariates, duration, event at float32 precision) against the HDF5 partitions. It never
uses row positions. A row gets a cohort only if all identical HDF5 records lie in the same
partition and counts agree. The match is accepted only if the HDF5 checksum is as above, the
record multisets are identical, every row is assigned, and partition sizes and event counts
equal 1546 / 968 and 686 / 299. In the HDF5 the two duplicated full records both lie in the
train (Rotterdam) partition, so no assignment is arbitrary. If accepted, membership is used
only to stratify the outer splits; it is never a predictor. If not accepted, nothing is written
and splits are stratified by event status only.

## Evaluation horizons

Horizons are external clinical conventions, fixed in `pilot_config.yaml` before any model is
fit. Their statistical support (0.2 <= S(t) <= 0.9, censoring survival G(t-) >= 0.3, and for tau
G(t-) >= 0.2 with >= 30 expected test patients at risk) is checked by `freeze_design.py` on the
development pool of outer split 0 only. Test outcomes are never used.

| dataset | horizons | primary t* | tau | rationale |
|---|---|---|---|---|
| SUPPORT | 180, 365, 730 days | 365 | 730 | 6-month (the SUPPORT prognostic model's horizon), 1- and 2-year survival |
| METABRIC | 60, 120, 180 months | 120 | 180 | 5-, 10- and 15-year overall survival |
| GBSG | 24, 36, 60 months | 60 (prespecified fallback 36) | 60 | 2-, 3- and 5-year recurrence-free survival; follow-up ends at 84 / 87 months |

The Stage 0 horizon table, computed on all records, is descriptive only and is not used to freeze.

## Censoring assumptions

Marginal IPCW, used by IBS/IPA, Brier(t*), Uno's C and time-dependent AUC, assumes:
1. censoring is independent of the event time and of the covariates;
2. the censoring survival G(t) stays positive up to tau (positivity);
3. the Kaplan-Meier estimate of G from the development pool applies to the test patients.

The Stage 0 censoring-model C was 0.540 for SUPPORT, 0.621 for METABRIC and 0.611 for GBSG. This
diagnostic cannot prove independence. The pilot keeps marginal IPCW. METABRIC and GBSG are flagged
for a prespecified conditional-IPCW sensitivity analysis in the full experiment, with a Cox
censoring model fitted on the development pool only. For GBSG the 84-month administrative end of
Rotterdam follow-up is one known source of covariate-related censoring.
